## Criteria and evidence

- Imported compiler, assembler, and linker options use a closed compatibility
  policy. Response files, specs, plugins, wrappers, forwarded output options,
  and target overrides were independently rejected before tool execution. The
  managed Cortex-M4, Thumb, and soft-float settings remain final.
- External tools write to a project-local mode-0700 staging directory. Outputs
  must be non-empty, regular, single-link files with the canonical staging
  parent before atomic promotion. The hard-linked-map regression preserved its
  external sentinel, and invalid staged output preserved the prior ELF and map.
- Every build-stage tool uses cancellable finite execution. The CLI SIGINT test
  returned structured `INTERRUPTED` output and exit 130, reaped the active tool
  and its process group, skipped later work, and removed staging.
- Object command stamps contain normalized argv plus the compiler path and
  executable SHA-256. Replacing compiler bytes rebuilt all fixture objects; a
  real stamp hash exactly matched the selected Arm GCC executable.
- Successful reporting requires every requested output and validates GNU size,
  flash/RAM bounds, ELF32 little-endian ARMv7E-M, EABI5, soft-float ABI, and a
  flash-resident entry point.
- Process execution uses direct program/argv construction without a shell. The
  original firmware repository remained clean and its `.cproj` SHA-256 remained
  `26cab00bfc1905162fa0a0da3b3c21921db96ce268e7bb9f68024d54e6f38051`.

## Verification results

- Formatting and strict Clippy with all targets/features passed.
- 58 locked workspace tests passed; two official installer archive acceptance
  tests remained ignored because their external archive variables were absent.
- All seven pipeline regressions, the active-build SIGINT CLI test, and the
  descendant process-group cancellation test passed independently.
- cargo-deny advisories, bans, licenses, and sources passed with only configured
  duplicate `syn`/`winnow` and unmatched-license warnings. cargo-audit loaded
  1,217 advisories, scanned 122 dependencies, and reported no vulnerabilities.
- Real Debug clean/incremental builds reported 35/0 then 0/35 compiled/reused,
  entry `0x00406379`, flash 31,260 bytes, and RAM 17,140 bytes.
- Real Release clean/incremental builds reported 35/0 then 0/35 compiled/reused,
  entry `0x004053d9`, flash 28,160 bytes, and RAM 17,108 bytes.
- Both configurations produced non-empty ELF, map, size, BIN, HEX, S-record,
  disassembly, and EEPROM artifacts with no residual staging directories or
  multi-link files.

## Findings and remediation

The first audit rejected M04 for imported-option confinement, linked-output
safety, build cancellation, compiler-identity fingerprints, and complete
artifact/ABI validation. Commit `1bb7676` remediated every blocking finding and
added regression and end-to-end coverage. The independent remediation audit
found no remaining blocker. M05 may begin.
